# Nowspace 0.5.6 — The Bucket panel shows the work, and a repeat can be traced

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Changed

- **Groups in the Planning tab's Bucket panel start expanded.** The panel
  exists to find something worth scheduling, and it was opening as a list of
  group names with every task hidden — so finding anything meant opening
  each group in turn, every time the panel opened. Groups now come up open,
  and folding one away keeps it folded for as long as you're working.

- **The panel lists Ready items only.** It used to include recurring copies
  that hadn't been sized yet, with an `s`/`m`/`l` shortcut to size them on
  the spot. The size is never shown in Planning and never used there, so it
  was asking for a decision in the wrong room. Unsized copies now sit with
  the rest of the unbound count under the panel, and are sized in the Bucket
  tab if and when they're worth scheduling. **The ready gate is unchanged:**
  Ready still means sized, and nothing else is schedulable, here or on any
  other route.

### Added

- **The ↻ on a planned task opens its schedule.** A repeating task in the
  week showed a ↻ that said only "this repeats" — not what it repeats on,
  not where it came from, and no way to change or stop it without going to
  look for it. Clicking it now switches to the Bucket, filters to what
  repeats, scrolls to that schedule — the live copy if there is one, the
  template itself if the copy is the one you're looking at — and opens it,
  ready to re-date, pause or stop repeating.

### Fixed

- **The horizon badge shows the horizon an item actually has.** A recurring
  task carries its horizon in its due date rather than an `n`/`nw`/`m`
  token, and the lens chips have always counted it that way — but the badge
  read only the token, so an item listed under **n** could show a bare `C`
  while its neighbour showed `nA`. Both the panel and the Bucket tab now
  show the same horizon the filters use, so a row always says where it sits.
