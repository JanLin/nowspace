# Nowspace 0.5.6 — The Bucket panel opens showing the work, and says where it sits

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Changed

- **Groups in the Planning tab's Bucket panel start expanded.** The panel
  exists to find something worth scheduling, and it was opening as a list of
  group names with every task hidden — so finding anything meant opening
  each group in turn, every time the panel opened. Groups now come up open,
  and folding one away keeps it folded for as long as you're working. The
  Bucket tab itself is unchanged.

### Fixed

- **The horizon badge now shows the horizon a recurring copy actually has.**
  A recurring task carries its horizon in its due date rather than an
  `n`/`nw`/`m` token, and the lens chips have always counted it that way —
  but the badge only read the token, so an item listed under **n** could
  show a bare `C` while its neighbour showed `nA`. The badge disagreeing
  with the chip that listed it made two rows in the same lens look like they
  came from different places. Both the panel and the Bucket tab now show the
  same horizon the filters use.

- **An unsized item shows its badge too.** Recurring copies are listed
  before they're sized so a tap on `s`/`m`/`l` can make them Ready right
  there — but showing those buttons *instead of* the badge left the row
  saying nothing about where it sits. It now carries the same `n`/`nw`/`m`
  and priority as everything else, flat rather than clickable: the badge's
  picker can file an item into a weekday, and nothing unsized is
  schedulable. A control that has to refuse is worse than no control.
