# Nowspace 0.5.6 — The Bucket panel opens showing the work

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Changed

- **Groups in the Planning tab's Bucket panel start expanded.** The panel
  exists to find something worth scheduling, and it was opening as a list of
  group names with every task hidden — so finding anything meant opening
  each group in turn, every time the panel opened. Groups now come up open,
  and folding one away keeps it folded for as long as you're working. The
  Bucket tab itself is unchanged.
