# Nowspace 0.5.8 — Adding to the bucket stops claiming it failed

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Adding a task to the bucket from the Planning panel said "Failed to add
  to bucket" on a task it had just added.** 0.5.6 opened the panel's groups
  by default by inverting the state it kept — expanded became collapsed —
  and one call was left pointing at the setter that no longer existed. It
  ran straight after the task was written, so the add succeeded, the error
  handler caught the fallout, and the message contradicted what had
  happened. The task is added, the group it went into opens, and nothing
  claims otherwise.
