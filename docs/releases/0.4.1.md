## Nowspace 0.4.1 — bucket edits no longer revert

Patch release, fully compatible with 0.4.0 (no data-format version bump;
mixed 0.4.x instances interoperate). Recommended for every installation —
it fixes a visible editing bug.

### Fixed

- **Editing a task's text made the bucket "reset itself" a few seconds
  later.** The save gate matched items by their text, so renaming,
  regrouping or linking a note on a migration-grandfathered Ready item
  (priority prefix, no size/steps yet) looked like a brand-new item
  entering Ready — the gate refused, and the edit was reverted. One
  refused item reverted the whole save, taking unrelated changes with it.
  Items now carry a stable identity (`~i` token, stamped automatically),
  so edits are matched to the same item and save cleanly.
- Renaming an item no longer resets its age-in-bucket stamp.

### Added

- **inbox** action on Ready items: demote a misclassified-Ready item
  (a migration artifact) back to Captured, from where it can be bound
  normally through the promotion questions.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
