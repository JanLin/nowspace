# Nowspace 0.5.9 — The task gets the line; its actions get the next one

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Changed

- **A task's action icons sit on their own row underneath it, at every
  width.** Inline, they take the room the task's text wants — a task worth
  writing a sentence about was being squeezed into two or three wrapped
  lines beside eight icons. They already dropped to a second row on phones;
  what that couldn't cover is a *narrow column on a wide screen*, which is
  most of the Planning tab's multi-day views and the whole of the Bucket
  list. A breakpoint asks how big the window is; the question that matters
  is how much room this row has.

  The task reads as a sentence across the full width, and the things you can
  do to it read as a row beneath. Both the Planning day view and the Bucket
  list.
