# Nowspace 0.8.7 — Take a habit back, and see which days it happened

**Patch release. No format change.**

### Added

- **A habit logged today can be taken back.** Tap one by accident and the
  chip now carries a small **↶** — press it and today's last log goes, the
  count steps down, and nothing else moves.

  Tapping the chip itself still means *I did it again*, because a sixth run
  on a 5×/week habit is a real thing. Undo is its own control rather than a
  second meaning for the same press.

  A habit you have done today also keeps its chip now, instead of leaving the
  strip — a chip that vanishes on the tap leaves an accidental one with
  nothing to undo it from.

- **Press a bar in the habits graph to see which days.** A small panel opens
  over the graph showing Monday to Sunday with the days it happened marked.
  Touch anywhere and it goes away. It is a glance, not a panel to manage.

  The per-day detail was already being worked out to draw each bar and then
  summed away; the graph just never showed it.
