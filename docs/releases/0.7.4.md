# Nowspace 0.7.4 — Habits fold away on every screen

**Patch release. No format change.**

### Changed

- **The habit strip starts folded, at every width.** It has been foldable on
  a phone for a while — `🌱 Habits · 2/4 on track ·▸`, one line, tap to open.
  On anything wider it was pinned open and pushed the first task down the
  page.

  Now it is the same everywhere: one line by default, press it to see each
  habit. The count on the fold is the part worth glancing at; the individual
  chips are for when you are logging one.

  The choice is remembered **per device**, like the text size — it is about
  the screen you are on, not something the vault should carry to every other
  installation. The 5-day and full-week grids follow the same fold, so
  putting habits away in one view does not leave them showing in another.

  Nothing about the habits themselves changed: same chips, same logging, same
  counts. There is still no nudge, no streak and no red anything — the fold
  shows what is on track and says nothing about what is not.
