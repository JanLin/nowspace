# Nowspace 0.8.0 — Habits go past the goal, pause, and show their progress

Minor release with **no bucket format change**: bucket schema stays at **4**,
so this installs alongside any 0.7.x instance sharing the vault. The habits
file gains one optional word, `paused`, which older instances ignore when
they read it — see *Your vault* below for the one thing an older instance
does with it.

### Added

- **A target is a floor, not a ceiling.** A weekly habit that has met its
  target used to disappear from the strip above your day, so the sixth run
  on a 5x/week habit had nowhere to be logged. Now its chip folds to a small
  ✓ that is still one tap away, and the count says **6/5**. The strip still
  shrinks as the week goes well — the chips get smaller instead of leaving.
  A daily habit leaves the strip once it's done today, as before.

- **Pause a habit to shift your focus.** Each row on the Habits tab has
  **⏸ pause**. A paused habit leaves the Plan tab and the "on track" count,
  keeps its row and its history, and comes back with **▶ resume**. The
  editor has a matching *paused* checkbox.

  Both days are written on the habit's line in `Plan Week Habits.md`, so it
  is readable and editable in Obsidian:

  ```
  - exercise: 5x/week, paused 2026-09-19
  - tai chi: 2x/week, paused 2026-09-01..2026-09-14
  ```

  The first is paused since the 19th; the second was paused on the 1st and
  started again on the 14th. A habit keeps every past pause. Pausing an
  already-paused habit keeps its original date, and pausing and starting
  again on the same day leaves nothing behind.

  A pause is a choice, not a lapse, so paused weeks are **skipped, not
  failed**: they don't count against "N of M weeks", and an established
  habit is still established when you start it again. A week you completed
  anyway still counts as met.

- **Each habit shows its progress over time.** Every row on the Habits tab
  carries a small graph: one bar per week for the last twelve weeks and this
  one, with a dashed line where a week counts as met — the target, or five
  days for a daily habit. Bars are never clamped, so a 6/5 week stands above
  the line. Met weeks are full colour, other weeks a quiet tint, a paused
  week is a dot and an empty week a gap. Nothing is red. Hover a bar for its
  number. It replaces the ▓░ strip in the same place.

### Changed

- **History reaches back twelve weeks instead of eight**, so the graph is
  long enough to show a trend.
- **Habit rows wrap on a phone.** The graph, the tally and the pause button
  move below the habit's name as one group, rather than squeezing the name to
  a word per line or drawing badges over the graph. Wider screens keep
  everything on one line.

### Your vault

Pausing only ever edits that habit's own line: comments, ordering and any
token you or a newer instance wrote are left exactly as they were.

An older (0.7.x) instance reading the same vault shows a paused habit as an
active one. If you **save the habit editor on an older instance**, it
rewrites the file without the pause words and the habit is un-paused. Nothing
else is lost — definitions, notes and every week's completions are
untouched — but upgrade every instance you edit habits from.
