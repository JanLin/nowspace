# Nowspace 0.7.5 — The bucket notices the file again

**Patch release. No format change.**

### Fixed

- **A bucket edited in Obsidian could stop reaching Nowspace until you
  reloaded the page.** The Bucket and Plan tabs watch their file by asking
  the backend for its timestamp every 30 seconds. The timestamp they compare
  against is recorded right after a load — and if that one small request
  failed, the failure was swallowed and the recorded value stayed empty.

  An empty value read as *unchanged*, so the comparison was quietly false
  from then on. The tab never unmounts (the app hides it rather than
  discarding it), so nothing re-read the file for the life of the page:
  every later edit, from Obsidian or from another device, went unnoticed
  until a manual reload. One blip on a phone's link or a backend still
  waking was enough to lose the rest of the session.

  Two changes. The bucket now takes the timestamp from the response it
  already received instead of asking a second time — one request that can
  fail instead of two. And where a timestamp still has to be asked for, not
  knowing one is treated as *changed*, not as *unchanged*: the view adopts
  the reading and re-reads once, which is the honest answer when what is on
  screen was fetched before it.

  Nothing else about refreshing moved: the same 30-second check, the same
  reload on focus and on returning to the app, and unsaved edits still get
  the banner rather than being pulled out from under you.
