# Nowspace 0.8.3 — A task's sub-group reaches the time log

**Patch release. No format change.**

### Fixed

- **Starting the timer on a task in a sub-group recorded it without one.**
  The entry came out as `Arratech: /9001: call with Issa`, which the time
  tracker reads as company *Arratech* and a description that happens to begin
  with a slash — so the hours never reached the sub-project they were worked
  on, and the distribution had nothing to show for them.

  The two tabs write the same idea differently, each to fit its own storage. A
  task keeps its sub-group inside its label — `Arratech: /9001: …` — so that
  the group heading in the week file stays untouched. A time entry has no
  heading to work with, so it carries both in the prefix: `Arratech/9001: …`.

  Starting a timer now translates between them. It is the one place a task
  becomes a time entry, so neither tab's own grammar had to change, and a task
  with no sub-group is passed through exactly as before.
