# Nowspace 0.5.15 — No typing numbers

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **A habit's weekly target could not be edited.** The field held one digit
  and refused to be emptied: it was a controlled input that fell back to `1`
  the instant you cleared it, so the old number reappeared as you deleted.
  The only way through was to select-all and overtype, or nudge the browser's
  own spinner.

  It's seven chips now — 1 to 7, the one in force highlighted — the same
  vocabulary as the weekday row in a repeat schedule and the priority
  badges. One tap, and a tap can't be half-done.

- **Minutes per occurrence has the same stepper as everything else.** `−`,
  the value, `＋`, in fives, exactly as "every N weeks" works in a repeat
  schedule. Zero reads as **untimed** rather than leaving you to know that
  0 means no timer.

- **The two number fields in Settings had the identical fault** — Shaping
  limit fell back to 4 and Notes kept open to 5 as you cleared them. Both
  are steppers now.

With those, nothing in Nowspace asks you to type a number: every value is a
chip, a stepper, or a picker.
