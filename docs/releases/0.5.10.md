# Nowspace 0.5.10 — The note opens at the top, and the diary clears the keyboard

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

Finishes what 0.5.7 started: that release made room to write on a phone,
but opening the notes still left them halfway down the screen.

### Fixed

- **Opening Notes or Diary scrolls them to the top, not merely into view.**
  `scrollIntoView` stops as soon as a box is visible and can't scroll past
  the end of the page, so the notes opened with the day's tasks still taking
  the screen. The page now reserves room below them and puts their top at
  the top, ready to type into. Assigned rather than animated — a smooth
  scroll is silently dropped in some engines, and this one has to land.

- **Focusing the note keeps it there.** The nudge that holds the note in
  place measured from the toolbar's bottom, and since 0.5.7 the toolbar
  stops sticking while you type — so it scrolled away and the measurement
  aimed far past the top. It measures from the page area now, in both
  directions.

- **The diary box fits what the keyboard leaves visible.** It was a fixed
  half-screen text box with no idea a keyboard existed, so on a phone the
  line being typed ended up underneath it. It's now sized to the visible
  viewport — which is what knows where the keyboard starts — and scrolls
  itself, which is all a plain text box needs to keep its own cursor in
  view. Full height again on a wide screen and when the keyboard closes.

- **The phone layout could get stuck deciding it wasn't a phone.** The
  stacked-layout flag treats an unmeasurable viewport as roomy, and a media
  query that is already true never announces a change — so on a window that
  hadn't been laid out when the tab first rendered, the answer stuck. It is
  asked again once there's a window to ask about.
