## Nowspace 0.4.3 — the bucket panel filters by horizon

Patch release on top of 0.4.2, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Added

- **Horizon chips in the Plan tab's bucket panel** — `n · nw · m · – ·
  all`, opening on `n`, the same vocabulary the Bucket tab uses. Each
  chip carries its count, computed over exactly what the panel can list
  (Ready items visible in the active context), so the number on a chip
  is what tapping it shows.
- The `–` chip holds Ready items with no horizon set — with a default of
  `n` and no such chip, schedulable work would sit invisible.
- An empty lens names where the rest is ("Nothing in `m` — 4 Ready items
  under other horizons") instead of reading as an empty bucket.

The help guide has described this behaviour since 0.3.x; the panel now
matches it. The lens filters what is listed, never what is schedulable —
items keep their real bucket index, so dragging onto a day and
tap-to-add still hit the right task.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
