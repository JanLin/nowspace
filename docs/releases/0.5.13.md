# Nowspace 0.5.13 — One owner for the note window on a phone

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Notes and Diary open with the top of the box at the top of the screen,
  and the bottom stays above the keyboard.** On Android this went wrong in
  two different ways — the note landing below where it should, the diary
  starting mid-screen with the keyboard over its lower half — while a
  desktop window narrowed by hand looked right. The difference is that a
  phone keyboard *resizes the layout* (`interactive-widget=resizes-content`)
  and the browser does its own scrolling of the focused field, so anything
  measured once at opening time is a guess that gets overwritten.

  Three things were setting that panel's geometry: the day view scrolled it,
  the notes panel set its own max-height and scrolled the page again, and a
  stylesheet capped its height at "the screen minus 260px of assumed
  chrome". On a desktop the three agreed often enough to look fine; on a
  phone, each keyboard event let a different one win.

  The day view now owns it alone, and re-applies it on every viewport
  change rather than once: top pinned to the top of the page area, height
  set to exactly what is visible. The other two no longer touch it — the
  stylesheet cap applies to the desktop column only, and the diary box fills
  the panel instead of measuring the screen for itself.

- **The diary opens at the end of the day's entry.** It focuses itself when
  it opens, and the caret was landing at the start — the wrong end of a
  diary. You come back to it to add to what's there, not to write above it.
  The day notes are unchanged: they show the text until you tap, and tapping
  starts the editing where you tapped.
