# Nowspace 0.5.19 — Moving a group leaves everything else alone

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Dragging a group gathered up the ungrouped tasks too.** Reordering groups
  rebuilt the whole day from a map keyed on group name — and ungrouped tasks
  share one key, the empty one. So every loose task in the day, wherever it
  sat, collected at the position of the first one the moment any group moved.
  Move a group and the tasks below it jumped above it, having never been
  touched.

  A group move now lifts only that group's own tasks and puts them back at
  the drop point. Every other task keeps its neighbours — the ungrouped ones
  included. Verified on a day with loose tasks both before and after the
  groups: `loose early · Arratech · Rotary · loose late one · loose late two`
  survives a Rotary→Arratech reorder with all three loose tasks exactly where
  they were.

- **A group could not be put after the ungrouped tasks at the end of a day.**
  Dropping a group on a row inserted it *above* that row, always — the
  midpoint that decides above-or-below for a task drop was read for the
  indicator but ignored for the drop. With the loose tasks last there was no
  row below them to aim at, so the group had nowhere to land but above.

  Group drops read the same indicator as task drops now: the lower half of the
  last row puts the group after it, the upper half above it. The bar at the
  foot of the list still drops a group at the very end, past everything.
