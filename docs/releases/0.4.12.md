## Nowspace 0.4.12 — Basic or Advanced

Patch release on top of 0.4.11, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Added

- **Settings › How you work** — the first section on the page, because it
  decides how much of the app you see.
  - **Basic** is plain GTD: groups, priorities, horizons (n / nw / m) and
    weekdays. Capture it, size up the priority, put it on a day.
  - **Advanced** adds the funnel: stages, the shaping question, t-shirt
    sizes, the weekly review and the Slate.
  - **Agent handoff** is an option inside Advanced — its own switch, so
    choosing Advanced doesn't hand you an agent surface, and it stays out
    of sight entirely on Basic. On by default only where agent areas are
    already configured.

  Advanced is the default, so nothing changes for anyone already using the
  funnel.

- **The size is reachable from the Plan too.** A task scheduled into a
  weekday carries its size, but the priority menu there never showed it —
  in Advanced it now offers s / m / l, and in Basic the menu is priority,
  horizon, weekday and bucket.
- In Basic the Bucket loses the stage lens, the Shaping strip, Review,
  Stats, the stage transitions and sizes in the priority menu, the stage
  pills, and the Slate behind the compass — leaving priority, horizon,
  weekday and group.

### Changed

- **Even in Advanced the Bucket toolbar is calmer:** Stage is its own
  cluster rather than more chips inside Filter, so one row is no longer
  three vocabularies deep — and what remains in Filter is labelled Group
  and Horizon, so it reads as the GTD filtering it is.
- **Scheduling in Basic doesn't require a Ready item.** With the funnel
  off there are no stages, so the rule that only Ready items reach a
  weekday is suspended along with the feature that gives it meaning. With
  the funnel on it is unchanged: still a refusal, never a warning.

### Your vault

Basic writes nothing funnel-shaped into your files, and leaves anything
already there untouched — stages, sizes and shaping questions stay
exactly as they are, ignored rather than erased. Switch back and the
funnel is as you left it, and an installation still in Advanced sharing
the same vault keeps working.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
