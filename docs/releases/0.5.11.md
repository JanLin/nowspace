# Nowspace 0.5.11 — Linking a note takes one tap, and a task keeps its line

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Added

- **A `+` on every row of the vault panel, to link that note into the note
  you're writing.** It existed in the day view, but only on hover — which on
  a phone means never — and it was missing from the Notes tab altogether.
  Now it leads every row in both places: folder-tree files, notes inside an
  expanded folder, search results, recently viewed and pinned.

  Adding a link **opens nothing**. It goes into the day's notes (or the note
  open in the Notes tab) and stays there for you to click when you want it.
  If the notes panel is closed the link is appended on the server, so
  nothing has to be open first, and a short confirmation says where it went.
  Tapping a note's *name* still opens it, as before.

- **Recently viewed and starred folders in the task-link picker.** The
  picker could only browse from the group's folder and search; it now offers
  the same two lists the vault panel does, from one shared recents list — a
  note opened while browsing is to hand when you come to link it to a task.

### Changed

- **A task's actions are a strip when its row has room, and a `⋯` menu when
  it hasn't.** 0.5.9 put them on a second row, which cost a line per task;
  this gives the line back. Nothing inline is an offer any more: the row
  carries only facts — waiting, linked, has steps, repeats — and everything
  you could do to the task is behind the strip or the `⋯` that follows the
  text.

  The choice is made on the width of **the row**, not the window: the Day
  view caps its list however wide the display, and a day column in the
  3-day grid is 379px on the widest screen there is. Below 28rem the actions
  collapse; above it they lay out inline. Both the Planning day rows and the
  Bucket.

- **The Bucket loses the vault panel.** Nothing there is written into, so
  browsing had no verb — the 🔗 on a task is the relationship that tab has,
  and reading notes belongs to the Notes tab.
