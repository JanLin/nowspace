## Nowspace 0.4.4 — the pinned toolbar stays pinned

Patch release on top of 0.4.3, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Fixed

- **The Tag / View / Filter bar drifted up under the top nav** on the
  Plan and Bucket tabs, hiding its first row. The app shell was sized
  with `100vh`, which on phones is the *large* viewport — it excludes the
  collapsible URL bar — so the shell stood taller than the visible area
  and the document itself gained that much scroll. The nav stayed put
  while everything below it slid behind the nav; the drift was exactly
  the URL-bar height. The shell now uses the dynamic viewport height, so
  the document has nothing to scroll and pinned means pinned.
- **Scrolling rows showed through above the pinned bar.** The main
  content area's own padding left a strip open between the nav and the
  bar. The bar now parks flush against the nav when stuck; where it sits
  at rest is unchanged.

Unpinning the toolbar still simply lets it scroll away.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
