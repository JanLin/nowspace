## Nowspace 0.4.13 — room to grow the text

Patch release on top of 0.4.12, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Fixed

- **The carry-forward rows keep their buttons on one line at larger text.**
  Each row showed the weekday it came from, which at a bigger size pushed
  the ✓ and ✕ onto a second line. The day now lives in the row's tooltip —
  the panel header already says which week these came from.
- **The priority badge is the same size everywhere it should be.** It was
  drawn at three different sizes — 12px in the Plan's day view, 10px in the
  Bucket list and the grid rows, 9px in the side panels — so raising the
  text size kept the Bucket looking shrunken next to the Plan. There are now
  two sizes and one rule: the full-size rows (Plan day view, Bucket list)
  match each other, and the compact surfaces (grids, bucket and carry
  panels, the shaping strip) share one smaller size instead of two.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
