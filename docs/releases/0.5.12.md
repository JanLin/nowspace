# Nowspace 0.5.12 — The type check starts checking, and three bugs it found

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Four inputs ignored their styling.** `AutoFocusInput` never accepted the
  `style` its callers were passing, so the quick-add fields in the Bucket
  rendered without their themed background. It takes it now.

- **The Help button in Settings passed a mouse event where a section name
  belongs.** `onClick={onOpenGuide}` hands React's click event straight to
  the function's first argument, so the guide was asked to open a section
  called `[object MouseEvent]`.

- **A bucket row's tooltip read "— from undefined".** It was rendering
  `from_day`, which belongs to carry-forward tasks, not bucket items — the
  markup had been copied across. It shows the task alone now.

### Changed

- **The pre-commit and CI type check now checks something.** `npx tsc
  --noEmit` — the command CI ran and CLAUDE.md prescribed — had no inputs:
  the root `tsconfig.json` is Vite's project-reference stub (`"files": []`),
  so it exited 0 on anything, including a file containing `const x: number =
  "definitely not a number"`. The step had been green for months while
  checking nothing, and `vite build` doesn't type-check either.

  Both now run `npx tsc -p tsconfig.app.json --noEmit`, and the 52 errors it
  had been hiding are cleared: 21 dead variables and imports removed, 7
  timer refs given the initial value React 19's types ask for, five `Task`
  literals completed, and four API return types corrected to match what the
  routes actually send (`saveRecurrence` returns its templates,
  `saveAppSettings` takes `funnel`, `vaultFolder`'s type is `"file" |
  "folder"`).

- **The day's tasks use the room when the notes are hidden.** The list was
  capped at 32rem whether or not the notes panel was open, so hiding it
  bought nothing — 483px with, 486px without. 42rem now: 646px with them
  hidden, and still a column rather than a line across a wide display.
