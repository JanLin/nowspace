# Nowspace 0.5.14 — Three from a morning on the Samsung

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Editing a task no longer drags the page down to the note.** The refit
  above listens for focus, because focus is what raises the keyboard — but
  it was listening for *any* focus, so tapping a task or double-tapping to
  add one scrolled the note into place and took the task line with it. It
  scrolls to the note only when the note is what has focus; the height still
  adjusts either way.

- **The week strip fits the screen at a larger text size.** Seven days and
  two arrows are wider than a phone once the text is turned up, and the row
  ran past the right edge with the last days unreachable — the header above
  it was fine, which is what made it look like the page itself was too wide.
  It wraps to a second line now, and only when it needs to.

- **The day notes and the diary are the same size.** They were 12px and
  14px, which reads as a mistake rather than a distinction. Both are 14px —
  editor, preview and headings.
