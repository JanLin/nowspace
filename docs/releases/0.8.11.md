# Nowspace 0.8.11 — File a piece of the day's notepad into the note it belongs to

**Patch release. No format change.**

### Added

- **Move selected notes into a vault note, with one press.** The day's notes
  are where a call gets written down in a hurry; they are not where it lives.
  Select the lines, open the vault browser, press the **✂** on the note's row.
  The text is filed into that note as a dated entry and a `[[link]]` is left
  where it was.

  The ✂ sits beside the existing **+**, which drops a link into what you are
  writing. They are deliberately two controls: the + can be undone by typing,
  this one takes text out of the day, and a button that does both would
  eventually do the wrong one. It appears only while the day's notes hold a
  selection, so it is never a control that would do nothing.

- **The entry goes to the top of the note's log.** Newest first: the call you
  just had is the one you read when you open a customer's note. Under the
  note's title, and above the entries it already keeps — so a note that opens
  with an action point list or a running tally keeps that block where it is,
  rather than having it pushed down one call at a time. The heading level
  follows the entries already in the note, so a note kept by hand keeps its
  own shape.

  A note's title is never treated as an entry, including the common case of a
  call note that is itself named for a date (`# 2026-07-29 call`).

- **Filing something does not take you out of the day.** The confirmation says
  where the text went and offers to open it. You are usually still in the call.

### Notes

- The new write uses the `expected_mtime` guard, so a note being edited in
  Obsidian at the same moment gets a refusal rather than being flattened.
- Selecting from the notes' rendered view is not supported yet — tap into the
  notes first, then select.
