## Nowspace 0.4.8 — writing a day note on a phone

Patch release on top of 0.4.7, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Fixed

- **The first line of a new day note was hidden while writing it.** The
  logic that keeps your typing above the on-screen keyboard was aiming the
  bottom of the note box at the visible edge rather than the caret — and
  the box is nearly half a screen tall even when empty, so on a fresh note
  it scrolled the whole panel down and took line one with it. It now
  follows the caret itself, wrapped lines included, and moves only when
  the caret would otherwise be out of sight — scrolling back up when it
  sits above the visible area.

### Changed

- **On phones, the note starts higher up.** Tapping into the day note
  parks it just under the pinned toolbar, so the day's tasks aren't taking
  half the screen while you write. Desktop layout is unchanged.
- The note panel now sizes itself to the *visible* viewport, so an
  on-screen keyboard shrinks the panel instead of leaving it full height
  behind the keyboard.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
