# Nowspace 0.5.3 — The repeat schedule fits the screen it's on

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **The ↻ repeat schedule is centred on a phone instead of hanging off the
  side.** The panel is a fixed 16rem, hung off the badge that opened it —
  fine on a desktop, but on a 375px phone at 140% text it measured 358px
  wide and started 53px *off the left edge*, which is both the off-centre
  look and the cut edge. Text size is applied as CSS zoom, so turning it up
  multiplies the panel's width against a screen that hasn't grown.

  Below the room to hang it off a badge, it now centres on the screen over a
  dimmed backdrop, capped to the screen's width and height — the cap divided
  by the text size, since `100vw` inside a zoomed page is wider than the
  glass. On a desktop nothing changes: same anchored popover, no backdrop.

- **The cadence row wraps rather than clipping.** Capped to a narrow screen,
  the panel can be narrower than `weekly / monthly / interval / every −N＋`
  wants, and the ＋ was being cut off — a stepper you can't press. It wraps
  onto a second line now.
