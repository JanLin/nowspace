# Nowspace 0.5.4 — Multi-day rows carry the task, not the toolbox

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Changed

- **The multi-day views drop their per-task action icons.** A day column is
  a third of a phone wide; seven icons on it — wait, track, pin, focus,
  break down, link, delete — is more furniture than task, and none of them
  is why you opened a multi-day view. What stays is the state you'd
  otherwise miss:

  - the **wait hourglass**, when the task is actually waiting;
  - the **link**, when the task actually has one (tap opens it, hold
    manages, as before).

  A focused task still reads as bold, and the priority badge, the tick and
  double-click-to-edit are all untouched. Everything removed is one tap
  away in the Day view, which is where those decisions belong anyway.
