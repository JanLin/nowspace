# Nowspace 0.8.4 — Hours already logged count towards their sub-project

**Patch release. No format change.**

### Fixed

- **Time entries recorded before 0.8.3 still showed no sub-project.** 0.8.3
  taught the timer to write `Arratech/9001:` when started from a task in a
  sub-group. It could not do anything about entries already in the log, which
  carry the task's own `Arratech: /9001:` — so those hours stayed under the
  company with nothing beneath it, and the distribution had a gap where the
  sub-project should be.

  The time tracker now reads both forms. An hour already logged does not have
  to be retyped to be counted, and nothing in your files is rewritten: it is
  the reader that became tolerant, not the log that changed.

  It still writes only one form — `Arratech/9001:` — so new entries are
  unchanged by this.
