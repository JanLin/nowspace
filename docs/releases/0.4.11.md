## Nowspace 0.4.11 — Settings loses the API key card

Patch release on top of 0.4.10, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Changed

- **The Claude API Key panel is gone from Settings.** It only reported
  whether a key was set and told you to edit `.env` — a read-only status
  card for a feature nothing currently reaches, since Coach and Dashboard
  are parked. The key still comes from the environment, so nothing about
  how it's provided has changed.
- **Whether Nowspace is ready to use now depends on the vault alone.**
  A configured key used to be required as well whenever the coach was
  enabled; with the panel removed that would have left you on a Settings
  page with nothing on it that could fix the problem.

The backend still exposes the key's status, so reviving the coaching
feature later needs no rebuilding.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
