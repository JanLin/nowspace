## Nowspace 0.4.7 — keep several notes open

Patch release on top of 0.4.6, fully compatible with every 0.4.x (no
bucket-format change; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Added

- **The Notes tab holds several notes at once**, one sub-tab each. Opening
  a note from a task's 🔗 or a `[[link]]` adds a tab instead of replacing
  what you were reading, and the strip survives switching to Plan or
  Bucket.
- **A limit you set** — Settings › Notes, five by default. Past it,
  opening another note closes the tab you've left unread longest.
- **📌 pins a note** so it's never the one closed to make room. Pinning
  more than the limit simply grows the strip: the number is where Nowspace
  starts tidying, not a wall, so following a link always opens.
- **Drag a sub-tab to reorder**, × closes one, and **Clear all** (with a
  confirm step) closes everything, pinned notes included.

The open set is stored in `Plan Week Configuration.md`, so the same notes
are open on every installation. Older Nowspace versions ignore the new
`notes` key and preserve it untouched when they save other settings, so a
mixed set of installations is safe.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
