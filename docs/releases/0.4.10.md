## Nowspace 0.4.10 — room in the top bar

Patch release on top of 0.4.9, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Fixed

- **The top bar no longer runs off the side of a phone.** On a 360px
  screen the row needed about 420 — logo, six tabs, then search, help and
  theme — so the theme control sat off the edge and squeezed everything
  before it. It now fits with room to spare.

### Changed

- **Theme moved into Settings**, as an *Appearance & help* section with
  Light / Dark / System as three buttons rather than one control you
  press repeatedly to guess your way round the cycle.
- **Help moved there too** — the guide, the tour and the philosophy, all
  in the same section. The tour's closing step points at Settings now
  instead of a button that no longer exists.
- **Search sits in the tab bar**, just before Settings, where it reads as
  one of the places you can go. ⌘K / Ctrl-K still opens it from anywhere.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
