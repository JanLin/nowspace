# Nowspace 0.8.8 — A habit chip is about the day you are looking at

**Patch release. No format change.**

### Fixed

- **The habit strip was always about today, whatever day you had open.** The
  tick state read today's count and a tap wrote to today's date, so opening
  Wednesday showed Friday's answer — and tapping there added a *second* line
  to Friday. That is how the same habit got ticked twice in one day.

  A chip is now about the day you are looking at. Wednesday shows what
  Wednesday did, a tap lands on Wednesday, and the undo takes back
  Wednesday's — **only ever that day's**, so a chip open on Thursday cannot
  reach back and remove Monday's tick.

  A daily habit already done that day takes no more taps: one a day is its
  whole meaning. A weekly habit keeps counting, because a second session on
  one day really is two towards 3×/week.

### Changed

- **A chip stays full strength whether or not the day is done.** It used to
  fade once ticked, which made the most useful thing on the strip — *not done
  today* — the hardest to read. Done shows a ✓ instead.

- **The week's target reached turns the chip green.** The one celebration on
  the strip; never a colour for the days without it.

- **Undo is the ↩ the toolbar already undoes with**, at full strength rather
  than a faint mark.

### Added

- **A habit logged on a day can be taken back from that day.** Press the ↩
  and the log goes, the count steps down, nothing else moves.

- **Press a bar in the habits graph to see which days.** A small panel opens
  over the graph showing Monday to Sunday with the days it happened marked.
  Touch anywhere and it goes away. It is a glance, not a panel to manage.

  The per-day detail was already being worked out to draw each bar and then
  summed away; the graph just never showed it.
