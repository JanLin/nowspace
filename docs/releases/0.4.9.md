## Nowspace 0.4.9 — one vault browser, and it can create

Patch release on top of 0.4.8, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2).

### Added

- **Make a note, a call note or a folder anywhere in the vault.** The
  Vault Browser now creates in whichever folder you have open. Previously
  only the Reference Files section could create, and only inside folders
  you had configured as references — so a call note about something new
  had nowhere to go until you had set the folder up in advance.
- **Search the vault by note name**, in the browser itself. Results
  replace the tree until you clear them, and each result has two targets:
  the name opens the note, the folder line under it browses to where the
  note lives — for when the point of the search was to file something
  beside it. It matches names, not what's written inside notes.
- **Reference groups sit at the top of the browser** as jump chips.
  Starring a folder still records it as a reference (in the vault
  settings, so every installation sees it); the chips are how you get
  back to those folders in one tap.
- **The Notes tab has the vault too**, behind the 📁 button in the corner,
  the same as Plan and Bucket. Anything you open from it becomes another
  sub-tab, so browsing and reading happen in one place — and the Notes tab
  now has a bottom status bar showing the open note's save state.
- Row actions carried over from the old section: insert a `[[link]]` into
  the day's notes, and scan a note for action points — now available for
  any note in the vault, not only ones in a reference folder.

- Deleting or moving a note now refreshes the vault index, so search
  can't offer a note that has gone.

### Changed

- **The Reference Files section is gone** from the day-notes panel.
  Starring a folder still marks it as a reference; it now works as a
  shortcut inside the browser rather than a second, weaker browser beside
  it.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
