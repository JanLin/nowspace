# Nowspace 0.5.1 — Writing in a note, without losing the line or the toolbar

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

Three things about the Notes tab editor, all reported together and all with
the same root: the editor's text box never scrolls itself.

### Fixed

- **The line you are typing stays visible.** The editor's textarea is
  `overflow: hidden` and grows to the full height of the note — the
  scrolling is done by the box around it, so the browser's own "follow the
  caret" had nothing to follow, and writing at the end of a long note put
  the current line under the fold. Nowspace now moves that box itself, and
  only when the caret has actually left the visible band. On a phone it
  measures against the visible viewport, so the caret clears the on-screen
  keyboard too.

- **The formatting toolbar no longer scrolls away.** The editor card was
  sized `100vh - 7.5rem`, a few pixels taller than the space it sits in,
  which was enough to let the page scroll and carry the toolbar — bold
  button and all — off the top. Worse at larger text sizes and with a
  keyboard open. The card is now measured against the dynamic viewport and
  the current text size, then trimmed to whatever is genuinely left, so
  there is nothing to scroll.

- **Bold and italic work from the keyboard and the toolbar.** ⌘B / ⌘I
  (Ctrl on Windows and Linux) are handled by Nowspace rather than left to
  the editor library, which bound them to its text box alone: with the
  cursor anywhere else — including just after picking out a phrase in the
  rendered half — the keystroke went nowhere, and the toolbar button marked
  up whatever had been selected in the source *last*, somewhere else
  entirely. Now a phrase highlighted in the rendered half is matched back
  to the source and marked where you meant it; with no selection at all,
  the word under the cursor is used; pressing the same shortcut again takes
  the markers back off. If the highlighted text appears more than once and
  can't be placed with certainty, Nowspace leaves the note alone rather
  than marking the wrong words.

### Internal

- The caret measurement shared by the day scratchpad and the Notes tab
  editor now lives in one place (`frontend/src/caretView.ts`).
