# Nowspace 0.5.5 — A caret that stays put, and a task that finds its group

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **Editing the bottom of a long note on a phone or tablet no longer jumps
  away from the end.** Keeping the caret in view meant reconstructing where
  it sits — a hidden copy of the text, wrapped the same way, measured to the
  caret. A phone doesn't wrap it quite the same (`text-size-adjust` alone is
  enough to change it), and on a long note the error compounds line by line
  until the measurement points somewhere else entirely — so the view
  obediently scrolled there. A desktop browser wraps both identically, which
  is why it only ever showed up on the Samsung and the iPad.

  The editor already paints a highlighted copy of the text behind the
  writing area, in the same box with the same wrapping. The caret is now
  measured off *that*, by asking the browser where the character actually
  is. Nothing to reconstruct, nothing to drift. If it can't be measured, the
  view is left alone rather than moved somewhere arbitrary, and the chase
  holds off mid-word while a phone keyboard is still composing.

- **A new task joins the group it names.** Since the add row moved to the
  top of the day, typing `Rotary: ring the venue` put it at the top — and
  because groups are runs of neighbouring tasks, that made a *second* Rotary
  heading above the first. It now lands at the end of the Rotary section
  that's already there, wherever in the day that is. Same for a group added
  by any route; a group that doesn't exist yet still starts where you typed
  it.
