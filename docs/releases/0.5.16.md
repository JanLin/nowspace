# Nowspace 0.5.16 — The same typeface everywhere a note is shown

Patch release: **no data-format change**, bucket schema stays at **3**, so
this installs alongside any other 0.5.x instance sharing the vault.

### Fixed

- **A day note was set in a different typeface from the diary on Android.**
  The markdown renderer ships its own font list — `-apple-system,
  BlinkMacSystemFont, 'Segoe UI', 'Noto Sans', …` — with no Roboto in it.
  On a Mac that lands on the same face as the rest of the app and nobody
  notices. On a phone none of the first three exist, so Nowspace resolved to
  Roboto and the rendered note to Noto Sans: same size, different letters,
  side by side with the diary.

  Everything a note is shown in now uses the app's own list, so it reads the
  same whether it's the day note, its preview, or a vault note in the Notes
  tab. Code keeps its monospace.
