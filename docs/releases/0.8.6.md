# Nowspace 0.8.6 — Carry-forward's tick and delete work again

**Patch release. No format change.**

### Fixed

- **Ticking or deleting an item in the carry-forward panel said "Internal
  error".** Both buttons called into a helper that was never written, so the
  request failed before it read anything. Nothing was damaged — the write
  never began — but neither action had worked since the panel gained them on
  9 July, in any week, for any task.

  Resolving an item now looks up the same week file the panel listed it from,
  which is what the two were always meant to agree on. Ticking marks it
  complete in last week's archived file; deleting drops the line.

  A task that is not in that file is a plain "not found", and a week that was
  never archived says so — neither is an internal error any more.
