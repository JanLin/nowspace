## Nowspace 0.4.2 — hyperlinks work in past weeks

Patch release, fully compatible with 0.4.0 and 0.4.1 (no data-format
version bump; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Fixed

- **Hyperlinks in past (read-only) weeks now work.** The day notes of an
  archive week always rendered as a raw read-only textarea, so markdown
  links and `[[wiki links]]` showed as literal source. Past weeks now
  render the same preview as the current week — links open, wiki links
  resolve to the note — while the text itself stays read-only: tapping
  it no longer opens the editor, and every write path from an archive
  week is closed (a dropped vault note used to leave a stuck "Unsaved"
  badge against a request the backend correctly refused).

### Also carried since 0.4.1

Merged to main but not yet in a tagged build — none of these changed the
data format either:

- **Task search across the week and the Bucket** (🔍 in the header,
  ⌘K / Ctrl-K) with scope chips, source-badged results and jump-to-task.
- **Ready = sized:** the ready gate requires only the s/m/l size, steps
  optional — a GTD-style task is its own next action. Still hard: an
  unsized item is refused. Tapping a size on a captured item now sizes
  it and marks it Ready in one step.
- Note editor on phones opens edit-only below 768px, with a Preview/Edit
  toggle; desktop keeps the split live view.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
