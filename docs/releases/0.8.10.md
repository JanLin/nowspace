# Nowspace 0.8.10 — Tick a habit in a week you already closed

**Patch release. No format change.**

### Added

- **A past week's habits can be ticked once the week is unlocked.** Forgetting
  to tick on Sunday and noticing on Monday is the ordinary case, not an edge
  one. Open the week, press **edit** — the same archive override that already
  lets a finished week's tasks be changed — and the strip appears, showing
  *that* week's counts rather than this week's. Ticks, undos and the seven
  dots all belong to the week on screen.

  Locked, the strip is not there at all: a past week shows nothing to tap
  until the intent to edit it is stated.

- **A day the week file never wrote can be back-filled.** The days that never
  got a heading — the Thursday you skipped entirely — now take a tick like any
  other, and the heading is written in the file's own shape: `##### Thu 5`
  beside `##### Mon 2`, not a bare `##### Thursday` that leaves the week
  looking half-edited. The shape is copied off the headings the file already
  has, so a file that writes `##### Monday` keeps writing `##### Thursday`.

### Changed

- **In a past week seen as a grid, the chips read but do not tick.** A grid
  has no day open, and "today" is in some other week — a tap there would have
  landed on whatever weekday today happens to be, in a week nobody was
  pointing at. The chips still show what that week holds and say *open a day
  to tick it*; the day view is where a past week is edited.
