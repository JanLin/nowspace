## Nowspace 0.4.6 — review the bucket one tag at a time

Patch release on top of 0.4.5, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Added

- **Tag lanes in the Bucket.** With tags configured (Work / Volunteer /
  Personal in Settings), the list splits into a lane per tag — a hairline,
  the tag's name, and how many groups and tasks sit under it — so a review
  can take one area at a time. **Clicking a lane's bar folds every group
  in it.** Groups with no tag, and un-grouped tasks, sit under Personal.
  Without tags configured the Bucket stays the flat list it was.
- **A ≡ handle on each group header**, as the Plan tab has: drag it onto
  another group to reorder, or onto a tag's bar to move the whole group
  under that tag. Re-homing writes the group's tag in Settings — the same
  mapping every surface reads, so the Plan tab's Tag filter agrees.
- **"Sort by tag"**, next to Sort GTD: orders the groups by lane so the
  file reads the way the lanes look. Each lane keeps its group order and
  each group keeps its task order.

A group's lane comes from its group→tag mapping alone, never from a
per-task `@w`-style override. One group has one home: a single tagged
task can't drag its group into another lane, or split it across two while
you're reviewing it.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
