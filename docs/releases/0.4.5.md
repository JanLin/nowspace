## Nowspace 0.4.5 — detach or re-point a task's linked note

Patch release on top of 0.4.4, fully compatible with every 0.4.x (no
data-format change; the bucket schema stays at version 2, so mixed 0.4.x
instances interoperate over the shared vault).

### Changed

- **🔗 tap opens the note, hold manages it.** A tap on the link icon
  opens the linked note straight away, as before. Holding it — or
  right-clicking on a desktop — opens the link manager instead. The rows
  are already busy with icons, so the one icon carries both jobs rather
  than growing a second control. A task with several links, or none, has
  nothing unambiguous to open, so a tap goes to the manager there.
- **Every 🔗 reaches the same manager.** Whichever view you're in — the
  Plan day view, the 3/5/7-day grids, the Bucket list or the binding
  strip — it's one popup listing what's attached. The second, thinner
  popup that the multi-day grids used has been retired; it could only
  open and add.
- **Each linked note carries Open · Change… · ×.** Open reads it, ×
  detaches it, and **Change…** points the link at a different note: a
  banner names the link being replaced, and picking (or creating) a note
  swaps it and stays put, because re-pointing is an edit of the task, not
  a request to read something. The swap rewrites the link where it sits
  in the task text, so its position and the rest of the line are
  untouched.

### Fixed

- **A link to a missing note no longer creates one behind your back.**
  Opening an unresolved link tries to resolve it once; if the note really
  is gone the row is flagged "not found", with Change… and × right there.
  Previously a typo in a link name quietly produced a new file in the
  group's folder.
- A note linked from the picker now appears in its Linked list
  immediately, instead of only after closing and reopening.

### macOS install note

If macOS reports the downloaded app as "damaged", it isn't — see the
README: after copying to /Applications, run
`xattr -cr /Applications/Nowspace.app` once.
