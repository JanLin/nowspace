# Demo data for screenshots

Fictional planning data (Acme, BrightCo — no real customers) used for the
README/blog screenshots. To retake them:

1. Copy these two files into a scratch vault's `0-Inbox/`.
2. Point a Nowspace instance at that vault (see the staging notes) — the
   day view renders the three contexts.
3. For the app-vs-Obsidian split, open the same scratch vault in Obsidian
   and show `Plan Week.md` in source mode next to Nowspace.
